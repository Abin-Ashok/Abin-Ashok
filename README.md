### PeopleHub – Cloud Infrastructure & Deployment

A full-stack application deployed using AWS cloud infrastructure and Kubernetes.

**Key Contributions**
- Provisioned and managed cloud infrastructure using Terraform.
- Deployed containerized applications using Docker and Kubernetes.
- Managed Kubernetes workloads and application deployments on Amazon EKS.

- Implemented CI/CD pipelines to automate application build and deployment.
